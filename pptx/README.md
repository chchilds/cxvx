# Tallgrass RIS Assessment Opportunity Deck

Generates the internal sales-enablement PowerPoint from the Tallgrass Region
IQ Onboarded Accounts & RIS Propensity Guide.

```bash
pip install -r pptx/requirements.txt
python3 pptx/build_tallgrass_ris_pptx.py
```

Output: `output/Tallgrass_IQ_Onboarded_RIS_Assessment_Opportunity_Guide.pptx`

The deck is Cisco Confidential (internal only). It does not contain credentials,
API keys, or customer secrets — only named-account propensity data from the
source enablement guide.
